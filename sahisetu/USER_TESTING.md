# SahiSetu — Rapid user-test sheet

Do not manufacture results. This sheet is for a small, honest pre-submission test with 5–10 people.

## Test goal

Measure whether a person can spot a licence-document issue, choose the safe correction, and identify the official next step more quickly and accurately with SahiSetu.

## Setup

- Use an incognito/private browser window for each participant.
- Start at `/apply?demo=rohan`.
- Use the supplied Rohan documents; do not ask participants for real documents or personal details.
- Ask them to change `Lakeview Road` to `Lake View Road`, confirm it, and resolve the difference.
- Then ask them to identify the official next step shown by SahiSetu.

## Optional comparison

Before showing SahiSetu, ask the same participant: “A new-address proof says `Lakeview Road`; an application draft says `Lake View Road`. What would you do before using the official service?” Record whether they name the exact proof wording and a safe official next step. Label this as an informal within-participant comparison, not a statistically representative study.

## What to report in the submission

- Number of participants and the exact task.
- Median completion time.
- Count who chose the exact proof wording.
- Count who identified Sarathi as the next official step.
- One observed failure or confusion point and what you changed as a result.

Use wording such as: “In an informal test with 6 participants using supplied demo documents, 5 identified the exact correction and official next step without facilitator help.” Only use numbers you actually collect.
